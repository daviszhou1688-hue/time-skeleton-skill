# 03 · 打卡登记闭环

用户在微信回复打卡后，Agent 解析并写入数据库，看板自动刷新。这是"提醒 → 打卡 → 登记 → 观测"闭环的最后一步。

## 登记闭环（一句话）

用户微信回复 → 解析日期+各项目状态 → 写入资料库数据库 → 回复用户确认。

数据源唯一是数据库，看板只读它。

## 打卡回复格式（灵活解析，不要求用户严格按模板）

用户可能回复任意一种，Agent 需灵活解析：

```
就寝✅23:40 起床✅7:10
口播✅
就寝❌熬夜刷手机 精力3
就寝打了
```

解析规则：
- 项目名后跟 ✅ / 🟡 / ❌ = 状态（✅达标 / 🟡弹性卡 / ❌未执行）
- ❌ 后面跟一句 = 未执行原因
- 精力N → 精力字段
- 模糊话（"就寝打了"）→ 按 ✅达标，拿不准就反问一句

### 时间戳规则（柱状图数据来源）

- **就寝时间 = 用户回复"就寝✅"那一刻的时间**（写进「就寝备注」）
- **起床时间 = 用户回复"起床✅"那一刻的时间**（写进「起床备注」）
- 用户主动附时间（如"起床✅7:10"）→ 用用户给的时间；没附 → 用消息到达时间，格式 `HH:MM`
- **怎么拿到达时间**：①会话上下文有消息时间戳则直接取转 HH:MM（北京时间）②拿不到用 shell `date '+%H:%M'` 取当前时间近似
- **睡眠时长算法**：前一天「就寝备注」→ 当天「起床备注」（跨天），深夜就寝跨午夜修正 `起床-就寝+24`，2~16h 有效

### 起床超时询问规则（8:30 之后回复才问）

- 起床 ≤ 8:30 → 直接 ✅，不询问
- 起床 > 8:30 → 先问原因（"今天 X:XX 才起，什么原因？"）
  - 确认不达标 → 计 ❌
  - 答复原因有道理（生病/通宵加班等）→ 计 ✅，但原因写进备注
- **就寝暂不询问原因**（以后需要再纳入）

## 登记步骤

1. **拿 token**：ToolSearch 查 `connect_open_platform` → DeferExecuteTool 调用 `{"toolName":"connect_open_platform","params":{"skill_id":"library"}}`
2. **查今日记录**：用资料库 `query_database_record.py` 查日期=今天（YYYY-MM-DD）的记录，拿记录 ID
3. **写库**：
   - 今日无记录 → `add_database_record.py` 新增
   - 今日有记录 → `update_database_record.py` 覆盖更新（不新增重复行）
   - 字段值格式：select 用 `{"select":"✅达标"}`，date 用 `{"date":"2026-08-24"}`，number 用 `{"number":3}`，text 用 `{"text":"..."}`
4. **回复确认**：一句简短确认，附看板链接

## 防错规则

1. 日期用今天，除非用户明确说补昨天
2. 先查再写，当天已有记录就更新
3. ❌ 必写原因，用户没写原因时按宪法提示补一句
4. 三态口径固定，不自创状态词
5. 拿不准的字段反问用户，不瞎填

## 交接文档模板

给微信 ClawBot 读的交接文档，用下面模板，替换 `<资料库ID>`、`<看板链接>`：

```
# 微信 ClawBot 打卡登记 SOP

## 关键 ID
- 看板数据库：<资料库ID>
- 看板页：<看板链接>
- 字段：日期(date)、就寝(select)、就寝备注(text)、起床(select)、起床备注(text)、未执行原因(text)、精力(number)、一句话(text)
- select 三态：✅达标 / 🟡弹性卡 / ❌未执行

## 登记闭环
用户微信回复打卡 → 解析 → 写入数据库 → 回复确认。

## 步骤
1. 拿 token（connect_open_platform, skill_id=library）
2. 查今日记录（query_database_record.py，日期=今天）
3. 有记录则 update，无记录则 add
4. 回复一句确认 + 看板链接

## 打卡格式
起床✅ ｜ 就寝✅ ｜ 起床❌熬夜 ｜ 精力3
规则：项目+✅/🟡/❌=状态，❌后跟原因，回复时间自动记时间戳（就寝/起床），精力N=精力

## 时间戳与超时
- 就寝时间=回复就寝✅的时刻，起床时间=回复起床✅的时刻（未附时间则用消息到达时间）
- 起床 > 8:30 → 先问原因；确认不达标计❌，原因有道理计✅但写原因
- 就寝暂不询问原因

## 防错
日期用今天；先查再写；❌必写原因；三态口径固定；拿不准反问
```

把这个交接文档写到用户指定的知识库位置，然后让用户在微信 ClawBot 发一句"读取这个文档，以后打卡按它登记"即可。
