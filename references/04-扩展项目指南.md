# 04 · 扩展项目指南

默认骨架只有「就寝 + 起床」两项。用户想加第三、第四个项目（如口播、午间冥想、运动、阅读等）时，按下面步骤扩展。

## 加一个项目要动 3 处

### 1. 数据库加字段

用资料库 skill 的 `add_database_field.py`，给数据库加一个 select 字段：

```json
{ "name": "新项目名", "config": { "select": { "options": [{"text":"✅达标"},{"text":"🟡弹性卡"},{"text":"❌未执行"}] } } }
```

### 2. 看板模板 ITEMS 数组加项目名

`assets/kanban-template.html` 里找到：

```js
var ITEMS = ['就寝','起床'];
```

改成：

```js
var ITEMS = ['就寝','起床','新项目名'];
```

看板的今日概览、本周周历表、14 天矩阵、达标率会自动多一行/一格（代码全走 ITEMS 循环，不用改别的）。

### 3. 加定时提醒任务

参考 `01-搭建步骤.md` 第 3 步，用 `automation_update` 新建一个提醒任务，rrule 按项目节奏定：

- 每天固定时间：`FREQ=DAILY;BYHOUR=X;BYMINUTE=Y`
- 指定星期：`FREQ=WEEKLY;BYDAY=MO,WE,FR;BYHOUR=12;BYMINUTE=0`
- 需"未打卡才提醒"：prompt 里先查数据库当日该字段，未打卡才推（参考就寝补提醒）

## 三态口径（任何项目通用）

- ✅达标 = 做到了
- 🟡弹性卡 = 计划内例外（聚餐/旅行/主动休息），每周每项限 2 张
- ❌未执行 = 忘了/没做到，**必须写原因**

## 注意事项

- **弹性卡每周每项限 2 张**：看板里已按"本周"统计已用/2，超额红字提示
- **防系统膨胀**：别一次加太多项目，建议先跑稳 2 项，再逐步加
- **加项目后全量检查**：确认看板各区块（今日概览/周历表/14天矩阵/达标率）都渲染了新项目，尤其注意有没有写死项目名的地方
