# Time Skeleton · 时间骨架打卡系统（Skill）

一套「规律作息 + 每日打卡 + 定时提醒 + 观测看板」的个人自律系统，打包成 **WorkBuddy 可复用的 Skill 技能包**。

让 AI Agent 读这个 skill 后，能自动帮你搭建：资料库数据库（就寝/起床打卡）→ 观测看板页 → 微信定时提醒 → 打卡登记闭环。

## 核心理念

- **管行为，不管生理结果**：只记 100% 可控的行为（关灯时间、离床时间），失眠/数据差不算失败
- **三态打卡**：✅达标 / 🟡弹性卡（计划内例外，每周每项限 2 张）/ ❌未执行（必须写原因）
- **看趋势不看链条**：滚动 14 天达标率 ≥80%，不做"连续打卡 N 天"这种焦虑型指标
- **防系统膨胀**：默认就寝+起床两项，跑稳后再按需扩展

## 系统组成（4 组件）

1. **资料库数据库** — 打卡数据唯一数据源
2. **观测看板页** — 今日概览 / 本周打卡 / 14 天滚动达标率 / 14 天打卡矩阵 / 起床时间趋势
3. **定时提醒任务** — 到点自动推送到微信（ClawBot 通道）
4. **打卡登记闭环** — 微信回复 → Agent 解析 → 写库 → 看板刷新

## 快速开始

1. 把这个 skill 安装到你的 WorkBuddy（`~/.workbuddy/skills/` 或项目 `.workbuddy/skills/`）
2. 让 Agent 读 `SKILL.md`，按 `references/01-搭建步骤.md` 分步执行
3. 全程会引导你：建数据库 → 发布看板 → 配微信推送 → 写打卡交接文档

## 依赖

- WorkBuddy 桌面端 ≥ 4.6.4
- 微信（用于 ClawBot 提醒推送，可选）
- 飞书（可选，作为另一个提醒/对话通道）
